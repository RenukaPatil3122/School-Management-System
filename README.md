# 🏫 School Management System

An all-in-one Android application developed using **Java** in **Android Studio** to simplify school administration tasks. The app supports both **teachers** and **students** with features like managing attendance, homework, timetables, syllabuses, and more — all in one place.

---

## 🚀 Features

### 👨‍🏫 For Teachers
- 📅 Upload and manage **Timetables**
- 📚 Upload **Syllabuses** (PDF format)
- 📝 Add and delete **Homework**
- 📢 Create and post **Notices**
- 🎓 Upload **Mark Sheets**

### 👩‍🎓 For Students
- 👀 View uploaded **Homework**, **Syllabuses**, **Timetables**
- 📢 View **Notices**
- 🎯 Track their **Attendance**

---

## 🛠️ Built With

- Java
- XML (for UI)
- Android Studio
- SQLite Database (for local data storage)
